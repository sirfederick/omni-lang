# Independent version identities

| Domain | Identity and authority |
|---|---|
| Integrated product | VERSION and compiler/src/omni.hpp: 0.1.0.00, WIP / NOT_RELEASED |
| Standard library | stdlib/omni.package.json: omni.std 0.8.4-alpha.8 |
| Public host ABI | Host SDK V1 and Invocation V1 symbols/headers |
| Invocation/schema frames | OMI1 / OMIS1 and their independent contracts |
| Representations | Wave/OMC, ONME, OSNMF and indexes: existing readers/writers/fences |
| Package/lock | Existing package and lock schemas, independent of product OVS |

Changing a product label does not renumber a format, relax authority or rewrite fixtures. Technical baseline labels in retained specs are not retrospective public releases. OVS uses four decimal fields; the last counts admitted coherent community contributions, not founder commits. The initial product counter stays 00. See [OVS](../governance/OVS-1.md).
