## Constitutional definition

> **An Omni program is a typed living computational system whose executable structure, identity, authority, distributed memory, semantic relationships, and operational state form an incrementally addressable and cryptographically verifiable computational nervous system.**

`Cryptographically verifiable` is deliberately narrow: hashes, roots and future attestations may prove integrity, identity binding, lineage, epoch continuity and artifact relationships under their declared algorithms. They do **not** prove external semantic or physical truth.

## AI-native, AI-independent

OSNMF exists with zero model providers configured. Deterministic check/build/eval/run, OSNMF, ONME, graph queries and epoch/pulse remain available if a provider or the Internet is absent.

- **OSNMF** — persistent systemic memory fabric and graph.
- **SisNervCent** — signalling/observation architectural plane; not replaced by OSNMF.
- **SIAREP** — resource/economic architectural plane; not replaced by OSNMF.
- **OCAP** — optional cognitive acceleration plane.
- **LLM/model** — replaceable cognitive engine, never systemic memory or authority.

> **One persistent computational body. Many replaceable cognitive engines.**

## Core invariants

1. `identity != content != authority`.
2. Observation/inference never becomes authority implicitly.
3. Structural/executable meaning remains governed by typed Omni semantics.
4. Routine introspection may consume OSNMF/ONME without source rescans.
5. Updates are represented as epoch changes plus incremental pulses.
6. Confidential memory never enters cognitive projections by default.
7. A proposal is not authority; publication is epoch/capability bound.
8. Particle/Wave/IR/Wire remain valid; ONME extends rather than replaces them.
9. Cryptographic verification is integrity/lineage verification, not truth oracle.
10. No remote provider is required for Core operation.
