# Contributing

Start with [DEVELOPMENT.md](DEVELOPMENT.md): check your environment, build the compiler, run an example, and execute the relevant MATRIX group. Review [specification authority](spec/README.md) before semantic changes. Test positive behavior and rejection cases; documentation changes need links and factual commands, not an indiscriminate full build.

The founder/maintainer is Federico T. Begna (@sirfederick). Original eligible contributions use MIT OR Apache-2.0; preserve third-party notices and author rights. Read the [Developer Certificate of Origin 1.1](https://developercertificate.org/) and use your genuine Signed-off-by for future commits. DCO does not replace provenance review or a cryptographic signature. No initial CLA is required. AI assistance stays under the submitting person's legal and technical responsibility.

No source should reference private consumers, secret paths or unrelated release receipts. Semantic/ABI/format changes need an explicit reviewed design and matching compatibility tests. Architecture decisions explain trade-offs and evidence. Follow [conduct](CODE_OF_CONDUCT.md) and [security](SECURITY.md). Public contribution/merge and release permissions require effective configuration, not prose alone.
